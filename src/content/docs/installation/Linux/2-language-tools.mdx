SplashKit supports multiple programming languages, each with its own set of tools. Follow the instructions below to install the required tools for your language of choice.

## Language-Specific Installations

### C# Tools

To develop with C# in SplashKit, you’ll need to install .NET:

<Tabs syncKey="linux-distro">
<TabItem label="Ubuntu/Debian">

<LinkButton icon="external" href="https://learn.microsoft.com/en-us/dotnet/core/install/linux-ubuntu" target="_blank">Install .NET SDK or .NET Runtime on Ubuntu</LinkButton>
<LinkButton icon="external" href="https://learn.microsoft.com/en-us/dotnet/core/install/linux-debian" target="_blank">Install .NET SDK or .NET Runtime on Debian</LinkButton>

</TabItem>
<TabItem label="Arch">

To install .NET SDK on Arch:

```shell
yay -S dotnet-sdk
```

To install only the .NET runtime (for running .NET apps without development tools):

```shell
yay -S dotnet-runtime
```

</TabItem>
<TabItem label="Fedora">

<LinkButton icon="external" href="https://learn.microsoft.com/en-us/dotnet/core/install/linux-fedora" target="_blank">Install the .NET SDK or the .NET Runtime on Fedora</LinkButton>

</TabItem>
</Tabs>

If the .NET installer does not automatically update your shell profile, you can manually add it by following the steps on the ['dotnet' command not found](/troubleshoot/linux/issue-6-dotnet-not-found) troubleshooting page.

### C++

For C++, you should already have the necessary tools if you have a standard Linux development environment. No additional setup is required specifically for SplashKit.

:::note

If you have issues with the SplashKit installation, when building the library, you may need to install the dependencies separately.

Run the following command to install the dependencies for your distro:

<Tabs syncKey="linux-distro">
   <TabItem label="Ubuntu/Debian">

   ```shell
   sudo apt -y install cmake libpng-dev libcurl4-openssl-dev libsdl2-dev libsdl2-mixer-dev libsdl2-gfx-dev libsdl2-image-dev libsdl2-net-dev libsdl2-ttf-dev libmikmod-dev libncurses-dev libbz2-dev libflac-dev libvorbis-dev libwebp-dev libfreetype6-dev build-essential clang libstdc++-12-dev g++ gdb jq moreutils
   ```

   </TabItem>
   <TabItem label="Arch">

   ```shell
   sudo pacman -S --needed base-devel cmake libpng sdl2 sdl2_mixer sdl2_gfx sdl2_image sdl2_net sdl2_ttf libmikmod clang jq moreutils
   ```

   </TabItem>
   <TabItem label="Fedora">

   ```shell
   sudo dnf install cmake libpng-devel libcurl-devel SDL2-devel SDL2_mixer-devel SDL2_gfx-devel SDL2_image-devel SDL2_net-devel SDL2_ttf-devel libmikmod-devel ncurses-devel bzip2-devel flac-devel libvorbis-devel libwebp-devel freetype-devel clang jq moreutils
   ```

   </TabItem>
</Tabs>

:::

### Python

Most Linux distributions include Python pre-installed. If Python isn’t installed, or if you need additional Python tools, follow the steps below.

<Steps>

1. **Installing Python**

    Install Python 3 and `pip` (Python package installer) using the following commands based on your Linux distribution:

    <Tabs syncKey="linux-distro">
    <TabItem label="Ubuntu/Debian">

    ```shell
    sudo apt install python3 python3-pip
    ```

    </TabItem>

    <TabItem label="Arch">
    <Tabs syncKey="package-manager">
    <TabItem label="With pacman">

    ```shell
    sudo pacman -S python python-pip
    ```

    </TabItem>
    <TabItem label="With yay">

    ```shell
    yay -S python python-pip
    ```

    </TabItem>
    </Tabs>
    </TabItem>

    <TabItem label="Fedora">

    ```shell
    sudo dnf install python3 python3-pip
    ```

    </TabItem>
    </Tabs>

2. **Verify Installation (Optional)**

    To confirm that Python and `pip` are successfully installed, check the versions:

    ```shell
    python3 --version
    pip3 --version
    ```

    Both commands should output version information if the installation was successful.

</Steps>
